## 🚀 Featured Project

### **GSU Job Request & Ordering System** 
**Full-Stack | Next.js 16 • React 19 • TypeScript • Express 5 • Sequelize 6 • MySQL 8**  
[`jayarpelicano01/GSU-General-Services-Unit`](https://github.com/jayarpelicano01/GSU-General-Services-Unit) • [Backend Repo](https://github.com/jayarpelicano01/GSU-System-Backend)

A complete job request workflow system for a university General Services Unit:
- **Multi-role access:** Unit Staff (submit), GSU Staff (manage/inspect), Personnel (execute), Unit Head (approve)
- **End-to-end flow:** Request → Inspection → Job Order → Materials → Execution → Completion Reports
- **Automated PDF generation** for Job Requests, Job Orders, and Accomplishment Reports
- **Real-time status tracking** with role-based dashboards
- Built during OJT at UEP GSU/ICT Department (Feb–May 2026)
